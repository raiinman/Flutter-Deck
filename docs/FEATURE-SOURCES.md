# Feature sources and limits
This catalog is a product-design proposal set, not a poll or a guarantee that every community request is represented. Each item remains proposed and explicitly declares its engine/service/content dependency.

Topics such as twin-stick/camera-relative movement, right-stick orbit, target switching/classic lock-on, dead zones, camera speed/inversion and widescreen/FOV/HUD are common requests for these games. No external implementation was incorporated into this app.

Other catalog items are launcher/product proposals and must be validated individually. Arbitrary framerate, rewind, gyro, HDR, randomizer and multiplayer are explicitly experimental or research-only. Licensed audio, game assets and translation content require appropriate rights; no such files were bundled.
