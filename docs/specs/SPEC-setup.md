# Setup wizard specification (UI preview)
Developer-requested setup flow for user-supplied game and BIOS selections. Current scope is explicitly simulated: no Browse/OpenFileDialog, paths, filesystem access, validation, imports or bundled game/BIOS files. Each MML1/MML2 target keeps separate in-memory sample selection flags. Three steps: target, sample selections, review. Both game and BIOS placeholders are required by the developer-proposed setup policy; this does not establish a verified technical BIOS/emulation dependency. Compatibility unknown for every file/edition. No legal/ownership guarantee is made by selecting a placeholder or checking the UI.

Acceptance: switching target preserves separate sample choices, forward/back controls, clear choices, review showing unknown compatibility, and a final preview-only message that cannot be mistaken for completed installation. Entry is a native top-deck Setup button. No integrations authorized. Compile/source checks only while runtime validation remains blocked.
