# Independent scaling module
Private developer-requested integration of original DSI Scaling 0.4.1 preview's Native.cs and Profile DTO only. Source engine preserved byte-for-byte as DsiNative.cs. No App.cs, backend, vendor DLL manager, runtime download, DLL replacement or injection. This is independent DWM thumbnail/GDI PrintWindow scaling, not the commercial Lossless Scaling product, LSFG, DLSS, or verified lossless output for every filter. User explicitly refreshes window list, selects one existing window and starts. No automatic capture, foreground fallback, remembered title, game execution, screenshot export or network. Window names stay only in UI memory. Default output windowed and stoppable; fullscreen/click-through intentionally not exposed pending UI validation. GDI supports Nearest/Bilinear/Bicubic/Integer; DWM ignores pixel-filter selection. Engine can show black/protected/accelerated content; integer refuses smaller output, PrintWindow may hang but existing single worker lease bounds overlap. No source window modification. Verification: compiler and pure Fit/filter geometry tests only. Do NOT run included original GUI lifecycle probes under current denied runtime boundary. Integration capture, output, stop and performance remain unverified. Licence: the developer stated on 2026-11-16 that DSI Scaling is their own work.
