Flutter Deck build tools: licences and notices
==============================================

This folder ("builder") holds what Flutter Deck needs to build a game from the player's own disc:
three builder kits, Python and Zig. No game files, BIOS files, game art or game audio are in it.

  kit\      the builder kit for Mega Man Legends
  kit2\     the builder kit for Mega Man Legends 2
  kit3\     the builder kit for The Misadventures of Tron Bonne
  python\   Python 3.15.2, the embeddable package for Windows 64-bit from python.org, unchanged
  zig\      Zig 0.17.1 for x86_64 Windows from ziglang.org, unchanged (one file added: THIRD-PARTY-NOTICES.txt)

2. Python
---------
python\LICENSE.txt is the licence file of the official package, unchanged: the Python Software Foundation
License Version 2, the additional conditions for the Windows binary build (Microsoft redistributable files),
and notices for some of the libraries packed with it (bzip2, libffi, Zstandard, Tcl/Tk and others).
Flutter Deck adds python\THIRD-PARTY-NOTICES.txt with the notices LICENSE.txt does not hold: the Python
documentation's list of incorporated software, and expat, mpdecimal, SQLite, xz, zlib-ng, libtommath and
HACL*, each copied unchanged from the source file it names.

3. Zig
------
zig\LICENSE is the licence of Zig (MIT licence, Expat form). zig\THIRD-PARTY-NOTICES.txt lists the other
licence files that come inside the Zig package.

4. Note on the kit's own notice
--------------------------------
kit\THIRD-PARTY-NOTICES.txt says the MIT text of the PlayStation video document will be added "here". The kit's
files are pinned and cannot change, so that text is in this file instead (section 1).
