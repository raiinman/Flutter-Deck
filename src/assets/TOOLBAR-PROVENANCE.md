# Toolbar icons provenance

- The 20 icons for pause, restart, stop, fullscreen and menu (normal, hover, pressed, disabled each) in `toolbar\` were cut on 2026-11-16 by `make-toolbar.ps1` (repository root) from the developer-supplied `Flutter-Ship-20-State-Sheet.png` (1312 by 1199, transparent background, SHA-256 `3EAA22E17A163C63C3F8B442C2029906F94398949773257AC517CC1C12BB20FD`). `sheet-mapping.json` is the mapping file that came with the sheet (cell and visible bounds of each icon); the script reads it and checks the sheet's hash first. The sheet itself is not stored in this repository; rerunning the script needs it.
- Each cut is a 200 by 200 window centred on that icon's own visible frame, so every icon and state registers the same way. Nothing is redrawn.
- What the sheet's mapping file says about itself (not established by this work): an approximate equal-cell mapping, generated frames may differ slightly, a faint alpha fringe can extend beyond the visible bounds. Its look is generated art; the earlier vector set the developer supplied the same day (`Flutter-Ship-Toolbar-Icons.zip`, SHA-256 `AFC1E2A4394E70682F5DE1A56F75F6786A9C36E753E26CC1EC960A637429DC10`) was tried first and replaced by this one at the developer's request. It is still in the developer's Downloads folder and is no longer used.
- **Derived by an AI assistant, not part of the developer's sheet:** `play-<state>.png` (four states). The sheet has no play icon and the overlay's music button needs one. `make-toolbar.ps1` takes each state's stop icon, erases the stop square (a straight blend of the face on either side, row by row) and draws a rounded play triangle in the square's own colour. The pressed state is flat where the sheet's own pressed icons have a slight emboss. The developer has not seen or accepted these.
- (Until 2026-11-17) the build embedded every PNG as `S-toolbar-<name>-<state>` (`build.ps1`). Each PNG is about 60 to 75 KB, so the launcher grows by about 1.6 MB.
- **Since 2026-11-17 these pictures are not embedded or used.** At the developer's request the overlay pill is drawn in code from the Flutter Deck pill kit's vector icons (SPEC-overlay.md, DECISIONS.md). The files stay here unchanged.
- Not established: how they look in the running launcher, at other screen scales, or over the game.
- Terms: the root `NOTICE.md` covers launcher artwork supplied by the developer.
